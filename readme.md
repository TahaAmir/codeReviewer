The Smart Code Reviewer automates static analysis by leveraging a powerful, free AI model (Meta's Llama 3 via Groq) to review code quality, find bugs, and suggest improvements.
The backend is built in Go using the Gin framework, exposing a /review REST API endpoint. When you submit a snippet of code, the backend securely forwards it to Groq's high-speed API. The AI acts as a developer and returns a strictly formatted JSON response—complete with a numerical score, letter grade, specific line-by-line issues, and overarching suggestions. This robust structure makes it incredibly easy to integrate into any frontend dashboard.
